# CompliCorp

CompliCorp is a digital accessibility testing and consulting firm that helps software vendors become procurement-ready with defensible accessibility evidence: manual WCAG audits, Section 508 testing, and VPAT/ACR reporting.

We provide manual VPAT testing and Accessibility Conformance Report (ACR) services for software vendors, evaluating real workflows with keyboard and screen-reader testing so the ACR holds up in RFPs, customer reviews, and procurement.

I bring 10 years of experience in digital accessibility, including work with publicly traded companies and vendors selling to large government agencies. We work with clients nationwide.
